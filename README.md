# Shelf & Spine

Your books on a walnut bookcase, with reading and listening from your Snug library.
Shelf & Spine installs beside Snug. Sign in with the same Snug account; downloads and appearance choices stay separate on each app.

## Install and keep updated

Why: Obtainium will install Shelf & Spine and keep its updates separate from Snug.

1. Open Obtainium on your phone and press **Add App**.
2. In **App Source URL**, type **https://github.com/wdanielz/shelf-spine-releases**.
3. To get test versions before everyone else, switch on **Include prereleases** in the options that appear below the address. While this page has only test versions, Obtainium installs only with it switched on.
4. Press **Add**, then **Install**. If Android asks whether to allow Obtainium to install apps, turn on **Allow from this source**, return to Obtainium and press **Install** again.
5. Open **Shelf & Spine** and sign in with your Snug account.

Keep your existing Snug entry in Obtainium. This page contains only Shelf & Spine updates.
New books receive artwork based on their own covers; a matched spine is used where one is available.
